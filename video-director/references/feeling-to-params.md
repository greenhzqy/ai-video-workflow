# 感觉 → 参数 翻译表

> **本技能的核心资产。** 用户说不清要什么，不是他的问题——是缺一张翻译表。
> 这张表把「高级感」「别像 PPT」「要燃起来」这类**人话**，翻译成管线**真实吃**的参数。
>
> 用法：A3 轮把下表**按用户的行**裁出来，逐行给候选让他确认/改。**不要念整张表给他。**

---

## 0. 可用的参数旋钮（先认清靶子）

这些是 `html-explainer` 真正会读的字段，翻译的**唯一合法出口**：

| 旋钮 | 取值 | 谁读 |
|---|---|---|
| `brief.mood` | `calm` / `neutral` / `high` | `style_director.py`（整条能量曲线抬/压） |
| `brief.pace` | `slow` / `medium` / `fast` | `style_director.py`（风格池偏好） |
| `brief.audience` | `general` / `pro` / `youth` | `style_director.py`（风格池加成） |
| `brief.aspect` | `16:9` / `9:16` … | `style_director.py` + 封面 |
| `scenes[].motion_intensity` | `0.0`–`1.0` | 帧作者（校准画面动势轻重） |
| `scenes[].primary` / `accent` | 风格目录 id | 帧作者（套哪个风格 DNA） |
| `scenes[].transition_out` | `cut` / `dissolve-soft` / `match-cut` / `iris-out` | `render_video.mjs` |
| `global.opener_variant` | 如 `kinetic-cascade` | `render_video.mjs` |
| `global.distinct_styles` | 3–4（片长相关） | 编排器多样性约束 |
| `--shutter 180` | 开/关 | 位移 > 80 px/帧 必开 |
| `theme`（7 项之一） | hex 色值 | `theme.css` CSS 变量 |
| `form`（7 项之一） | 纯视觉 / 主视觉+章节讲解 / … | 决定走讲解模式还是宣传片模式 |

**动作用词**出口在 `assets/motion.js`（40+ 词汇，5 组）与 `video-shotcraft` 的 125 张镜头卡。

## 1. 主表：人话 → 参数

| 用户会说的话 | 翻译成 | 具体参数落法 | 反面（会踩的坑） |
|---|---|---|---|
| **「高级感」** | 低饱和 + 大留白 + 慢而稳的运镜 + 长停留 | `mood:calm`；`pace:slow`；`motion_intensity` 0.35–0.5；每场 `slowPush` 0.04–0.07；配色低饱和（明度差 > 对比度）；**禁** glitch / 霓虹 / 快切 | 把"高级"做成"空"——留白 ≠ 没内容，须有**一个**强焦点 |
| **「别像 PPT」** | 承接 + 运镜 + 禁纯淡入 | 承接连律（相邻场**至少一个元素跨边界继续动**：`morphBox`/`irisOpen`/`diveInto`/`arcHop`）；**每场 ≥1 可测运镜**；慢动作**禁用纯 `opacity` 淡入**，改用 `riseWord`/`springIn`（带位移） | 只加"入场动画"不加"承接"——每拍各自淡入正是 PPT 的签名 |
| **「要燃 / 炸裂」** | 强冲击 + 强过冲 + 快切 | `mood:high`；`pace:fast`；`motion_intensity` 0.75–0.95；`impact` + `camShake` + `riser` 音效；曲线用过冲（`back(2.2)`）；**必开** `--shutter 180` | 全片都 0.9 = 没有对比 = 不燃。**燃要有落差**，前后各留一拍慢的 |
| **「有节奏 / 卡点」** | 硬切锚在重音 + 高密度 B() | `pace:fast`；每场 ≥1 次**硬切**落在重音上；`B()` 锚点密集（一句 ≥2 处）；`transition_out` 多为 `cut` | 卡点卡在**画面**却没卡在**声音**——两者不同源就不叫卡点 |
| **「电影感」** | 胶片质感 + 强景深 + 慢推 + 暗角 | `frame-light-leak-cinema` 基因；低对比 + 颗粒；`depthBlur` 强；`slowPush` 长镜头；考虑上下黑边；`mood:calm` | 用了电影配色却每 0.5s 一个快切——质感与节奏打架 |
| **「干净 / 清爽」** | 单一强调色 + 大网格 + 零碎屑 | 瑞士网格 / 极简留白基因；accent **只给当前重点**；背景只有幕底 + 网格；文字 ≥22px | 为了"干净"把信息也删掉 → 变空洞 |
| **「科技感」** | 冷色 + 网格 + 扫描线 + 快切 | 冷色系（靛蓝/青）；网格背景；`frame-glitch-title` / 电光工作室基因；`motion_intensity` 0.6–0.8 | 科技感 ≠ 到处 glitch。**glitch 是标点不是正文** |
| **「温柔 / 东方」** | 暖色 + 缓曲线 + 无硬切 | `frame-takram-organic`；暖色/低对比；曲线走 `sineInOut`；`transition_out` 用 `dissolve-soft`；`mood:calm` | 全片无硬切 → 节奏糊掉。缓 ≠ 没有节拍 |
| **「信息量大」** | 数据风格 + 密度控制 | 数据类风格（NYT 图/数据滚动/瑞士网格）；**每场只讲一个数**；字幕块 ≤16 字 | 把信息量大做成"字多"——观众读字就不看画面了 |
| **「短平快」** | 短时长 + 少场景 + 高密度 | `duration_sec` 压到下限；场景数砍到最少；`motion_intensity` 抬高 | 时长压到 15s 还想塞 8 个点 → 每点 1.9s，什么也没讲清 |
| **「有冲击力的封面」** | 大字钩子 + 悖论视觉 | `cover`：大字钩子 ≥96/120/130px（按画幅）+ **核心悖论视觉**（两数对照/一升一降/分裂线）+ 四边留白；**独立排版不是裁切** | 封面文字与首帧钩子不同义 → 点进来就退出 |
| **「想让人看完」** | 前 3 秒定生死 + 落差 | 开场 `motion_intensity` 拉高（0.75+）做钩子；每 20–30s 一个"高光时刻"；结尾回扣开场 | 把最精彩的放中段——绝大多数人在前 3 秒就走了 |

## 2. 形容词 → 三组候选（把开放题变成选择题）

用户说了一个模糊词时，**不要让他继续解释，直接给三档让他挑**：

### 「节奏」
| 档 | `pace` | `motion_intensity` | 切场 | 适合 |
|---|---|---|---|---|
| **A 娓娓道来** | `slow` | 0.30–0.45 | 少，`dissolve-soft` | 科普深讲、纪录片感 |
| **B 稳健推进** | `medium` | 0.45–0.65 | 中，`cut` 为主 | 大多数讲解片、产品介绍 |
| **C 强节奏** | `fast` | 0.70–0.95 | 密，`cut`/`match-cut` | 卡点片、宣传片、社媒 |

> 问法：「你想要 A 娓娓道来 / B 稳健推进 / C 强节奏，哪一档像你脑子里的那个？想不出来就看你发在哪——抖音选 C，B站长视频选 B，内部分享选 A。」

### 「视觉密度」
| 档 | 每场元素 | 留白 | 风格倾向 |
|---|---|---|---|
| **A 极简一个焦点** | 1 主 + 1 辅 | 大量 | 瑞士网格 / 奢华极简 |
| **B 信息图式** | 1 主 + 2–4 辅 | 中等 | 数据类 / 概念图 |
| **C 满屏运动** | 多层 + 背景动 | 少 | 故障艺术 / 流体 Hero |

### 「温度」
| 档 | 色温 | 曲线 | 转场 |
|---|---|---|---|
| **A 冷静理性** | 冷（靛/青） | `expoOut` 干脆 | `cut` |
| **B 中性专业** | 中性（纸白/墨黑 + 单 accent） | `cubicInOut` | `cut` / `match-cut` |
| **C 温暖感性** | 暖（琥珀/米白） | `sineInOut` 缓 | `dissolve-soft` |

## 3. 参数自洽性红线（A3 收尾时自查）

翻译完把表横过来看，这几对**不能互相矛盾**：

| 组合 | 为什么错 | 怎么改 |
|---|---|---|
| `mood:calm` + 故障艺术/电光工作室 | 情绪与画面语法相反 | 换风格，或改 `mood` |
| `pace:fast` + `motion_intensity < 0.5` | 说快但动势弱，成片会"赶而无力" | 抬 `motion_intensity` 到 0.7+ |
| 全片 `motion_intensity` 全同一个值 | 没有起伏 = 平 = 单调 | 排一条起伏曲线，落差 ≥0.2 |
| 全片 `transition_out` 全 `cut` | 硬切连着硬切 = 生硬 | 至少 1/3 换 `dissolve-soft`/`match-cut` |
| `duration_sec` 短 + 场景数多 | 每场不足 2s，什么也讲不清 | 砍场景或加时长 |
| 亮底配色 + 未配亮底字幕皮肤 | 白字落米白纸面 = 看不见 | 主题里补 `--mg-sub-fg` 等四项 + `<body class="paper">` |
| 位移 > 80 px/帧 + 未开快门 | 重影成串 | `--shutter 180` |

`spec_review.py` 会机械查这些；**但先人工过一遍**，脚本只能抓写进 JSON 的，抓不到"你根本没写"。

## 4. 一句话记忆法

> **感觉是形容词，参数是数字。**
> 「高级」→ `mood:calm` + `intensity 0.4` + `slowPush 0.05`
> 「燃」→ `mood:high` + `intensity 0.85` + `back(2.2)` + 快门
> 「别像 PPT」→ 承接 + 每场运镜 + 禁纯淡入
>
> 说不出数字 = 还没想清楚；说不出感觉 = 让他**挑**，别让他**想**。
