# 社交钩子引擎（流量向）

> **为什么需要这一层**：`mediastorm-copywriter` 产出的是**5–8 分钟长视频口播稿**
> （黄金七段式 / 2500–4500 字 / CTA 是「三连 + 那么我们下次再见」）。
> 那是**B站长视频逻辑**。社交平台（抖音/小红书/视频号）是**另一套引擎**：
> 前 3 秒决定 90% 完播率，封面决定点击，标题决定推荐分发。
>
> **本文件补的就是这个差值**：把飓风式的「钩子 + 升维」压缩进前 3 秒，
> 并接上平台原生机制。写文案时**两个一起用**：飓风管内容厚度，本文件管分发效率。

---

## 0. 两种逻辑的根本差异（先认清靶子）

| 维度 | 长视频（B站/YouTube） | **社交平台（抖音/小红书/视频号）** |
|---|---|---|
| 生死线 | 前 30 秒 | **前 3 秒**（甚至第 1 帧） |
| 观众心理 | 「我要搞清楚这件事」 | 「**凭什么让我停下**」 |
| 决定成败的指标 | 完播率 + 互动 | **前 3 秒跳出率 + 完播率 + 封面点击率** |
| 钩子位置 | 第 1 句开始，可铺垫 2–3 句 | **第 1 帧就要有视觉钩子，第 1 句就要有信息钩子** |
| 结构 | 黄金七段式 | **黄金三拍**（见 §2） |
| CTA | 「三连 + 下次再见」 | **平台原生**（评论引导/关注理由/下期预告），**绝不说"下次再见"** |
| 金句 | 结尾升华用 | **做钩子用**（前置！） |
| 长度 | 2500–4500 字 | **60–200 字**（15–60 秒） |

> **一句话**：长视频是「**我把这事讲清楚**」，社交平台是「**我凭什么让你停下来**」。
> 两者的钩子写法**相反**——长视频的钩子可以慢慢展开，社交平台的钩子必须**压缩到第 1 帧**。

---

## 1. 钩子三重奏（社交平台专用）

**社交平台的钩子不是一句话，是三个通道同时开火。** 任一通道缺席都掉完播率。

| 通道 | 时机 | 作用 | 常见错误 |
|---|---|---|---|
| **① 视觉钩子** | 第 1 帧 | 让人**停下手指** | 用 logo 开场 / 用标题卡开场 / 前 3 秒画面静止 |
| **② 文字钩子** | 第 0–3 秒同屏 | 让人**明白有信息量** | 文字与口播重复（浪费一个通道） |
| **③ 声音钩子** | 第 0–3 秒 | 让人**愿意听下去** | 前 3 秒是音乐渐入 + 无口播 |

### 三重奏的对位写法（照这个排）

```
第 1 帧   视觉钩子：反常识画面 / 极端特写 / 数字冲击 / 结果前置
第 1 句   文字钩子：与口播【不同角度】的文字（不是重复！）
第 1 句   声音钩子：直接开讲，句首就是结论或疑问
```

**示例（同一主题，两种写法）**：

| | 长视频写法（飓风式） | 社交平台写法 |
|---|---|---|
| 第 1 句 | 「这是一枚硬币。准确地说，这是一枚用 AI 生成的硬币…」 | **「这枚硬币是 AI 生成的，它有 50% 概率正面朝上吗？」** |
| 前 3 秒 | 展示硬币（画面平稳） | 硬币**从屏幕外砸进画面**+ 大字「AI 硬币」+ 口播直接抛结论 |
| 差异 | 铺垫 → 展开 | **结论前置**，铺垫全砍 |

## 2. 黄金三拍（替代黄金七段式的短视频骨架）

把飓风的七段压成三拍。**每拍的时长是硬约束。**

```
拍 1 · 钩子（0–3s）      三重奏同时开火：视觉 + 文字 + 声音
                          └ 必须是【结论 / 反常识 / 冲突】，不是"背景介绍"

拍 2 · 兑现（3–25s）      立刻给出「所以呢」—— 承诺的信息必须在 25 秒内开始兑现
                          └ 每 5–8 秒一个小转折/新信息点（防划走）
                          └ 这里才是飓风「分点主体」的地方，但要砍到极简

拍 3 · 收尾（25–35s）      ① 回扣开头的钩子（形成闭环）
                          ② 一句可复述的结论（这是"转发理由"）
                          ③ 平台原生 CTA
```

### 与飓风骨架的映射

| 飓风七段 | 短视频 | 处理 |
|---|---|---|
| ① 钩子 | **拍 1** | 保留，但压缩到 3 秒内；视觉通道要另加 |
| ② 升维立意 | 拍 1 尾部 / 拍 2 首 | **砍到一句**，不能占 2–4 句 |
| ③ 合作方植入 | — | **短视频默认不要**（掉完播率）；要植入就放拍 3 前 |
| ④ 分点主体 | **拍 2** | 3–5 点砍到 **1–2 点**，每点 = 现象 + 一个数据 + 一个类比 |
| ⑤ 转折深入 | 拍 2 内部 | 变成一个「但是」即可 |
| ⑥ 升华畅想 | **拍 3 第②条** | 压缩成**一句**可复述的结论 |
| ⑦ CTA | **拍 3 第③条** | **必须换成平台原生**（见 §4） |

## 3. 六类钩子的短视频适配

`mediastorm-copywriter` 的 6 类钩子（见其 `references/hooks.md`）**全部可用**，
但每类在短视频里要**加视觉通道**、**砍掉铺垫**：

| 飓风钩子类型 | 短视频适配 | 视觉钩子必须是什么 |
|---|---|---|
| 1 实物/微观特写 | 保留，但物体要在**第 1 帧就占满屏** | 极端特写（不要全景再推近） |
| 2 反常识/悬念设问 | **最好用**，但要**先给答案的一半** | 反常识画面的定格 |
| 3 观众处境代入 | 保留（「你是不是也…」高效） | 痛点场景的一帧 |
| 4 极端场景白描 | 保留，视觉冲击天然强 | 就是那个极端场景 |
| 5 人物/身份前置 | 慎用（陌生人在短视频里没信任基础） | 人脸 + 身份字幕 |
| 6 栏目 IP + 仪式 | **短视频不适用**（没人认识你的栏目） | — |

**钩子句式速查（社交平台版，比飓风版更短更狠）**：

```
结果前置   「我用 XX 做了 YY，结果 ZZ」           ← 最强，通用
反常识     「XX 竟然不是 YY，而是 ZZ」
代价/损失  「别再用 XX 了，你正在 YY」
数字冲击   「3 秒 / 100 块 / 一个动作，YY 了 ZZ」
身份代入   「如果你是 XX，这条一定要看完」
悬念       「XX 的真相，和你想的完全相反」
```

## 4. CTA：平台原生（**禁止直接搬飓风的 CTA**）

飓风的 CTA 是「点点小心心 + 关注 + 那么我们下次再见」——**那是 B站话术**。社交平台要用：

| 平台 | 原生 CTA | 禁止 |
|---|---|---|
| 抖音 | 「评论区告诉我」「你站哪边」（**引导评论=推流**） | 「下次再见」（完播率杀手） |
| 小红书 | 「收藏起来慢慢看」「评论区蹲一个」（收藏=权重） | 硬广口吻 |
| 视频号 | 「转发给需要的人」（**转发=社交推荐**） | 站外引导 |
| B站 | 可用飓风的「三连」话术 | — |

**铁律**：CTA 必须在**最后 3 秒**，且**只给一个动作**。给两个动作 = 用户一个都不做。

## 5. 平台差异速查（决定一切下游参数）

| 平台 | 画幅 | 黄金时长 | 钩子窗口 | 封面 | 关键指标 |
|---|---|---|---|---|---|
| **抖音** | 9:16 | 15–45s | **1s** | 16:9 + 3:4 | 完播 + 评论 |
| **小红书** | 9:16 或 3:4 | 30–90s | 3s | **3:4**（主页格子） | 收藏 + 点赞 |
| **视频号** | 9:16 或 16:9 | 30–60s | 3s | 16:9 | 转发 |
| **B站** | 16:9 | 1–10min | 30s | 16:9 | 三连 + 完播 |
| **YouTube** | 16:9 | 按内容 | 30s | 16:9（自定义缩略） | 点击率 + 留存 |

**联动下游参数**（写进 `brief.json` 与 `feeling-to-params.md`）：

| 平台 | `aspect` | `pace` | `motion_intensity` | `cover` 张数 |
|---|---|---|---|---|
| 抖音 | 9:16 | `fast` | 0.75–0.95 | 16:9 + 3:4（+9:16） |
| 小红书 | 9:16 | `medium`→`fast` | 0.60–0.80 | **必须 3:4 + 9:16** |
| 视频号 | 16:9 | `medium` | 0.55–0.75 | 16:9 |
| B站 | 16:9 | `medium`→`slow` | 0.45–0.65 | 16:9 + 3:4 |

## 6. 标题与封面（分发层，常被忽略）

**视频做得好但标题/封面烂 = 没播放。** 这两项在社交平台**与内容同等重要**。

### 标题三律

1. **含具体数字或名词**（「3 个方法」优于「一些方法」）
2. **含冲突或反常识**（「竟然」「其实不是」「别再用」）
3. **≤ 20 字**（超出被截断）

**平台差异**：
- 抖音：标题权重低，**钩子在前 3 秒**（标题只做补充）
- 小红书：**标题权重极高**（搜索+推荐双入口），必须埋**搜索关键词**
- B站：标题+封面共同决定点击

### 封面三要素（与视频首帧的关系）

见 `aesthetic-review-layers.md` 与下游的封面规范。社交平台特有三条：

- **封面 ≠ 首帧截图**：封面是**独立排版**，要放「大字钩子 + 悖论视觉」
- **封面文字必须与视频首帧钩子同义**（不同义 = 点进来就退出）
- **9:16 竖版**：上边距 ≥180px、下边距 ≥160px（让开平台 UI）

## 7. 文案验收（机械可查部分）

写完后逐条过，`spec_review.py` 会查前面几条：

| # | 判据 | 级 |
|---|---|---|
| 1 | 第 1 句**不含**「大家好 / 今天我们来聊聊 / 这期视频」 | FAIL |
| 2 | 第 1 句 ≤ 20 字（微信/抖音前 3 秒读得完） | WARN |
| 3 | 全文字数落在平台区间（抖音 60–200 / 小红书 150–400 / B站不限） | FAIL |
| 4 | CTA **不含**「下次再见」（社交平台） | FAIL |
| 5 | CTA 只给**一个**动作 | WARN |
| 6 | 至少一处**数字或具体名词** | WARN |
| 7 | 结尾**回扣**开头钩子（闭环） | WARN |
| 8 | 有**可复述的一句结论**（转发理由） | WARN |
| 9 | 长视频才需要：飓风 10 条硬规则逐条过 | — |

## 8. 与两个技能的协作姿势（**重要，含一个真实冲突**）

### 推荐流水线

```
① mediastorm-copywriter   出内容底稿（长视频逻辑：钩子 + 升维 + 分点 + 数据换算 + 类比）
        │                  用于：B站/YouTube 长视频；或作为短视频的「素材池」
        ▼
② 本文件（社交钩子引擎）   改写为社交平台版：压缩成黄金三拍 + 加视觉钩子 + 换平台原生 CTA
        │                  用于：抖音/小红书/视频号
        ▼
③ humanizer-zh            去 AI 味（见下方冲突说明）
        ▼
④ video-director V1 验收   逐条过 §7 判据
```

### ⚠️ 一个真实冲突（必须知道）

**`mediastorm-copywriter` 要求「结尾升华 + 落一句金句」；
`humanizer-zh` 要求「删除金句——如果听起来像可引用的语句，重写它」。**

这两条**直接矛盾**。怎么处理：

| 场景 | 用谁的规则 | 理由 |
|---|---|---|
| **B站长视频口播** | **听飓风的**（保留金句） | 长视频靠情绪沉淀，金句是记忆点 |
| **社交平台短视频** | **听 humanizer 的**（删金句） | 短视频的金句会显得**说教/摆姿态**，掉完播率；转发理由靠「一句结论」而非「金句」 |
| 品牌向 / 企业宣传 | 折中：保留**一句**克制结论 | — |

> **判据**：把金句读出来，如果像**演讲结尾**→ 短视频里删掉（改成人话结论）；
> 如果像**跟朋友聊天时的随口总结**→ 可以留。

### 去 AI 味的重点（`humanizer-zh` 挑出来的高频症状）

社交平台文案最常见的 AI 味：
- **三段式排比**（「不仅…而且…更是…」）→ 改成两项
- **破折号揭示**（「——这才是关键」）→ 删掉破折号
- **夸大意义**（「标志着」「见证了」「彰显了」）→ 直接说事实
- **模糊归因**（「专家认为」「数据显示」）→ 给具体来源或删掉
- **每句等长** → 打断节奏（短视频尤其，短句要有）

### 什么时候**不用** humanizer

- 需要**刻意工整**的场合（品牌口号、系列片固定开场）
- 已经自然口语的稿子（过度处理会失去锋芒）

## 9. 一句话记忆法

> **长视频：把事讲清楚。社交平台：凭什么让你停下。**
>
> 社交平台三件事，缺一不可：
> **① 第 1 帧抓眼 ② 第 1 句抛结论 ③ 结尾给一个动作**
>
> 飓风给你**厚度**，这份文件给你**效率**，humanizer 给你**人味**。
