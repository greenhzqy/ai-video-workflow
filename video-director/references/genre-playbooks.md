# 片型剧本（五种）

> A1 定完 `form` 后，直接跳到对应剧本，**照它的骨架走**，别临场发挥。
> 每个剧本给：目标 / 时长 / 结构骨架 / 参数默认 / 专属坑。
>
> 参数默认是**起点**，A3 轮要让用户确认或改。

---

## 1. 讲解片 / 科普（`form`: 主视觉 + 章节讲解）

| 项 | 值 |
|---|---|
| **目标** | 观众看完「搞清楚了这是什么」 |
| **谁在用** | `html-explainer` 的**默认模式**（讲解模式） |
| **时长** | 1–8 分钟（＜1min 塞不下机制，＞8min 要分章） |
| **节奏来源** | 字幕块（`B()` 节拍器），解说吐字时刻 |

**结构骨架**（按 `style_director` 的八角色走）：

```
opener(钩子) → statement(背景/问题) → mechanism(原理) → data(数据佐证)
   → contrast(反常识) → conclusion(收束) → outro(落版)
```

**参数默认**：
```
mood: neutral    pace: medium    audience: general
motion_intensity: 开场 0.70 → 中段 0.50 → 收尾 0.42
distinct_styles: 3–4     transition: cut 为主 + 每 3 场 1 次 dissolve-soft
```

**专属坑**：
- **信息过载**——每场只讲一个点。信息量大 ≠ 字多。
- **结尾废句**——`A 或者不 A` 的同义反复 / 复读标题的自指句 / 鸡汤式留白，三类稳定废句。
- **数据口径**——画面数字必须逐个对调研 URL，二手转述会偷换统计主体。拿不到一手口径**宁缺勿用**。

---

## 2. 宣传片 / 发布片（`form`: 纯视觉 or 主视觉+章节）

| 项 | 值 |
|---|---|
| **目标** | 观众**被击中**（已知是什么，要「被说服它有多好」） |
| **谁在用** | `html-explainer` 的 **showcase-mode**（宣传片模式，去模板化） |
| **时长** | 10–150 秒 |
| **节奏来源** | **动作的因果链**，一拍引发下一拍 |

**结构骨架**：
```
一记钩子(最强视觉) → 三个卖点各一拍 → 一处对比/反转 → 高光 → 落版
```

**参数默认**：
```
mood: high       pace: fast       audience: youth（社媒）/ pro（B端）
motion_intensity: 0.75–0.90，但**中段留一拍慢的**做落差
distinct_styles: 2–3（宣传片换太勤会碎）
```

**六条设计律（硬指标，B2 会机械查）**：
1. 每场**一个主语**，其余都是它的结果
2. 每个反应都有原因（撞击→溅开、入场→挤压回弹）
3. **承接而非替换**——相邻两拍至少一个元素跨边界继续动
4. **运镜是默认，静止是例外**——每场 ≥1 次可测运镜
5. 硬切只给硬事件
6. 位移 > 80 px/帧 **必须开快门**

**专属坑**：
- **套模板**——成片能被认出「这是 bold-signal 模板」= 去模板化失败。只吸纳配色/字体/时序三层。
- **全片都燃**——没有落差就不燃。前后各留一拍慢的。
- **搬运 gsap 模板代码**——会得到**静止首帧且零报错**。必须用 `motion.js` 重写。

## 3. 纯视觉卡点短片 ★ **（你的主力片型）**

| 项 | 值 |
|---|---|
| **目标** | 视觉冲击 + 情绪推进，不承载信息 |
| **谁在用** | `showcase-mode` + `beat-sync-editing` + `video-shotcraft` 镜头卡 |
| **时长** | 15–60 秒 |
| **节奏来源** | **音乐重音**（不是解说吐字） |

**结构骨架**：
```
冷开场(0–3s 最强钩子) → 蓄势(渐强, 强度爬升) → 爆点(重音对齐) 
   → 回落(留白一拍) → 二次爆点 → 收尾定格
```

**参数默认**：
```
mood: high       pace: fast
motion_intensity: 0.40 → 0.60 → 0.95 → 0.35 → 0.90 → 0.50（一条完整起伏）
transition: cut 为主，重音处硬切；`iris-out` 收尾
shutter: 必开 180
```

**专属坑（这类片最常翻车的四条）**：
- **卡点卡错层**——画面卡在重音，声音却没卡在同一处。**两者必须同源**：先定音乐重音时刻表，再让画面节拍锚上去。
- **强度拉平**——全片 0.9 = 疲劳 = 不燃。必须**先降后升**。
- **没有承接**——每拍各自淡入淡出，正是 PPT 签名。用 `morphBox`/`irisOpen`/`diveInto` 串。
- **长镜头静止**——>3s 没动观众以为卡了。用 `slowPush`。

**做这类片前必查**：`video-shotcraft` 的 `references/shots/`（125 张卡，10 类：开场/运镜/转场/字体/UI入场/交互/数据/光影/节奏/收尾）——**这是你的动效词汇表，别自己从零想**。

## 4. 产品介绍 / 功能演示

| 项 | 值 |
|---|---|
| **目标** | 观众知道「这解决什么问题、怎么用」 |
| **时长** | 30–90 秒 |
| **节奏来源** | 问题→方案的因果链 |

**结构骨架**：
```
痛点场景 → 转折(但是) → 方案登场 → 三个功能各一拍 → 结果/数据 → 落版(CTA)
```

**参数默认**：
```
mood: neutral→high    pace: medium    audience: pro
motion_intensity: 0.55 → 0.70 → 0.45
```

**专属坑**：
- **念提交记录**——用户不关心你改了什么，只关心他能多做什么。
- **先讲功能后讲问题**——没有痛点铺垫，功能没有重量。
- **真实组件接入**——如需挂真实产品组件，那是 `html-explainer` 宣传片范式 + GSAP 主轴的活。

---

## 5. 口播 / 讲解视频（有真人或配音为主）

| 项 | 值 |
|---|---|
| **目标** | 人讲、画面配合 |
| **时长** | 任意（口播语音驱动） |
| **节奏来源** | **词级语音对齐**（word-level） |

**参数默认**：
```
motion_intensity: 0.35–0.55（画面是配角，别抢）
transition: 以 cut 为主，跟着语义断句切
```

**工具**：`video-talkcraft`（109 张运动配方卡 + 反幻灯片相机系统，专门为此设计）。

**专属坑**：
- **画面抢戏**——口播片的画面是标点，不是主语。
- **卡点卡在停顿上**——口播的节拍在**语义断句**，不在音量峰值。
